## Acceptance examples for future implementation

1. For an authorized app feature, Orbit reads project rules, records acceptance and
   a bounded dependency plan, assigns configured capable agents, creates an isolated
   branch/worktree from recorded base/configuration, implements and runs relevant
   approved tests/builds. A failure leads to a fix/recheck without another “continue”.
2. An actual distinct reviewer inspects the change and evidence. Rejection returns
   through revision/recheck/review; selecting an identity or asserting “approved”
   does not establish reviewer execution. Orbit prepares a reviewable PR and asks
   Rosh for explicit merge authorization. Changed head/conflicts block integration;
   after authorized integration, verify actual result/update status. Completion
   alone never merges. Restart reconciles uncertain effects rather than duplicating PRs.
3. Missing subscription access produces an actionable blocker without paid API
   fallback or hidden provider switch. Material scope/cost/permission choices ask
   a human; routine authorized tests/fixes/status updates do not. Worktrees do not
   replace process permissions or protect against every filesystem race.
4. Reuse an agent identity in an Atelier development project and a separate website
   photo project. Each assignment receives only its project’s granted context and
   files; no implicit shared history, roots or grants. Folder registration creates
   no `.git` and requires no branch or PR.
5. “Resize these photos for the website” resolves a supported workflow plus selected
   sources, dimensions, JPEG quality and destination. Consequential missing values
   clarify; preview separate outputs/collisions, preserve originals and execute
   approved implemented handlers. Verify output dimensions/format/integrity and
   visual evidence as applicable; report succeeded/failed/skipped files. Risk-based
   policy can allow routine conversion without a second agent; critical effects
   remain gated. No generic image capability is inferred from today’s UTF-8 runner.
6. Directly invoke the same pinned workflow when routing is offline. Unknown action
   versions/handlers, invalid mappings/graphs, traversal/symlink escape, secret
   access and undeclared network fail closed. File instructions cannot widen grants.
   A local model proposes schema-shaped parameters, never executable shell text.
7. A destination occupied after preview or changed source invalidates application.
   Cancellation/restart/partial publication records completed/failed/unknown effects
   in retained recovery evidence; reconcile before retry. Recovery cannot overwrite
   later user edits. No atomicity/universal reversibility claim. In-place replacement,
   deletes or destructive changes wait for separately scoped approval/recovery.
